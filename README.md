# Issues Frame Legal Research Dataset

This repository is intended to document a collection of 300 court documents
for a research paper by Sarmad Mahar. The collection covers:

- Plaintiffs' plaints
- Written statements
- Replications
- Applications
- Court orders
- Judgments

The 300-document total is the overall collection size; counts for each document
type have not been specified.

## Dataset availability

This repository currently contains documentation only. The source documents
have not been provided and are not included.

Before adding documents, ensure they are authorized for research use and handle
personal or sensitive information in accordance with applicable approvals and
requirements.
